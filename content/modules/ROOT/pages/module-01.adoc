= Package and Deploy Bootable LAMP Image

== Introduction

In this module, you'll transform your LAMP application into an **immutable bootable container image** and deploy it as a virtual machine. You'll learn how production deployment with Image Mode differs from the development workflow you learned in Lab 1.

**What you'll accomplish:**

* Review the LAMP application files
* Create a systemd service for database initialization
* Write a production Containerfile with COPY directives
* Build a bootable container image
* Create a VM disk image with bootc-image-builder
* Deploy and test the application as a virtual machine

**Time:** Approximately 35 minutes
