= Package and Deploy a Bootable LAMP Image

== Overview

Learn how to transform a LAMP application into an **immutable bootable container image** and deploy it as a virtual machine using **Image Mode for RHEL**. This lab teaches the production deployment workflow using bootable containers.

This is **Part 2** of a 2-lab series on **Image Mode for Application Developers**.

== What You'll Learn

In Lab 1, you built a LAMP application using **volume mounts** for fast development iteration. In this lab, you'll package that same application for **production deployment** using Image Mode concepts:

**Development (Lab 1):**
- Volume mounts (`-v`)
- Mutable (files can change)
- Fast iteration

**Production (Lab 2):**
- COPY directives
- Immutable (files baked into image)
- Consistent, repeatable deployments

== Learning Objectives

By completing this lab, you will be able to:

* Create production Containerfiles with COPY directives instead of volume mounts
* Build bootable container images using `rhel-bootc` base images
* Create systemd services for application initialization
* Use `bootc-image-builder` to create VM disk images
* Deploy bootable images as virtual machines
* Understand the differences between development and production workflows

== Target Audience

This lab is designed for:

* **Application developers** learning to package apps with Image Mode
* **Software engineers** deploying containerized applications to production
* **DevOps engineers** implementing immutable infrastructure

== What's Different About This Lab?

**From Lab 1 (Development):**

Lab 1 taught you to use **volume mounts** where files live on the host and are mounted into the container. This is perfect for development - you can edit files and see changes immediately.

**This Lab (Production):**

You'll use **COPY directives** in the Containerfile to copy files into the image at build time. The image becomes **immutable** - files can't change after the image is built. To update the application, you build a new image.

This immutability is a key concept in modern production deployments.
