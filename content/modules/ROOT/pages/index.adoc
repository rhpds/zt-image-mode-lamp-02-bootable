= Lab 2 of 2: Package and Deploy a Bootable LAMP Image

[.lead]
This is **Lab 2 of 2** in the Image Mode LAMP series. Lab 1 taught fast development with volume mounts. This lab takes the same application and ships it as an **immutable bootable image** you deploy as a VM.

*Time: ~35 minutes | Difficulty: Intermediate | Series: Image Mode LAMP (Part 2 of 2)*

== What you should focus on

* **Same app, new packaging** — you are not rewriting the LAMP application; you are changing how it is delivered
* **COPY, not mounts** — production files are baked into the image at build time
* **Boot once, serve traffic** — MariaDB, Apache, PHP, and DB init start automatically
* **Immutable value** — reproducible boots, versionable artifacts, no snowflake VM setup

== Why Image Mode matters here

Most Image Mode content targets platform teams (OS hardening, updates, fleet management). This series targets **application developers**:

* You still use Containerfiles and container tooling
* You deliver a full OS + application artifact operations can boot anywhere a VM runs
* You keep a clean split between **iterate fast** (Lab 1) and **ship immutable** (Lab 2)

image::dev-vs-prod-compare.svg[Comparison table of Lab 1 volume-mount development versus Lab 2 COPY and bootable production packaging,width=1000,align=center]

== What you'll build

A bootable disk image that starts a complete LAMP stack:

* RHEL bootc operating system
* MariaDB + Apache + PHP
* Your app files copied into the image
* systemd services enabled for first boot
* Firewall/SELinux configured at build time

No post-boot hand configuration. Boot the VM and validate.

== Lab flow

**Module 1 — Prepare production configuration**  
Review app files and create the first-boot database init service.

**Module 2 — Build the bootable image**  
Write the production Containerfile, build `lamp-bootc`, convert to `disk.qcow2`.

**Module 3 — Deploy and validate**  
Start the VM, prove services and HTTP from the terminal, then enable the Showroom LAMP Application tab.

== Prerequisites

* Basic command-line and container familiarity
* Comfortable with the idea of a LAMP stack (Linux, Apache, MariaDB, PHP)
* Lab 1 completed **or** willingness to use the provided app files in this environment
